# Tax Consultant Expert
Live Demo: https://tax-consultant-expert.vercel.app/
A professional tax consultancy web platform built to showcase services and company information through a structured, elegant layout.
## Tech Stack
- React.js (Vite)
- Bootstrap
- JavaScript, SCSS, HTML
## Features
- Services section for tax consultancy services
- About and Why Choose Us sections
- Contact section
- Clean, responsive layout for mobile and desktop
## Run Locally
npm install
npm run dev
